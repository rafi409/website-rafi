## Menjalankan preview di VS Code

1. Pastikan Node.js sudah terpasang.
2. Buka folder proyek ini di VS Code.
3. Tekan **F5**, lalu pilih konfigurasi **Preview Portfolio** jika diminta.
4. VS Code akan menjalankan server lokal dan membuka website di Chrome.

Alternatif: tekan **Ctrl+Shift+B** untuk menyalakan server preview, lalu buka
http://localhost:8080 di browser. Hentikan server dengan menekan **Ctrl+C** di
terminal yang menjalankannya.
